# 📘 Algorithm Practice

A collection of algorithm problems and solutions for daily practice. This includes problems from platforms like **LeetCode**, **HackerRank**, and classic **Data Structures & Algorithms** exercises.

## 📌 Purpose

- Sharpen problem-solving skills.
- Prepare for technical interviews.
- Understand common patterns in algorithms.

## 🧠 Topics Covered

- **Data Structures**
  - Arrays, Strings
  - Linked Lists, Stacks, Queues
  - Trees, Graphs, Heaps
  - Hash Maps & Sets

- **Algorithms**
  - Sorting & Searching
  - Recursion & Backtracking
  - Dynamic Programming
  - Greedy Algorithms
  - Graph Traversal (DFS, BFS)
  - Sliding Window, Two Pointers
  - Binary Search, Divide & Conquer

- **LeetCode Practice**
  - Easy, Medium, and Hard problems
  - Solutions with code and explanations

## 🚀 How to Use

- Clone this repo:  
  ```bash
  git clone https://github.com/your-username/algorithm-practice.git
  cd algorithm-practice
  ```

- Browse by category or difficulty.
- Run JS files directly with Node.js:
  ```bash
  node leetcode/easy/two-sum.js
  ```
